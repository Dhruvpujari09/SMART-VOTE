Connect the Arduino

Plug the board into this computer with USB, upload the included Arduino sketch, then select its serial port using Connect Arduino. Use Chrome or Edge for USB serial access.

Button wiring

Wire one push button per candidate between the Arduino pin and GND. The sketch uses internal pull-ups: D2 · Candidate 1, D3 · Candidate 2, D4 · Candidate 3, D5 · Candidate 4.

Demo only: counts are held in Arduino memory and clear when the board restarts. This prototype is not designed or certified for a real election.
